Disclaimer. This is a reference tool built and maintained by tk.cpa. Every date shown is computed live from a stored recurrence rule (a statutory day-of-month plus the standard weekend/federal-holiday shift-forward convention), not looked up from a single-year table, so dates project correctly into past and future years alike. Federal individual, business, payroll, excise, estate/gift, exempt-organization, and international information-return rules are sourced from IRS Publication 509 (2026) and current form instructions, cited per entry. State individual income tax, state corporate/franchise tax, state sales tax, state unemployment insurance, state estimated tax, state pass-through entity (partnership/S-corp) return due dates, and 8 city/local tax jurisdictions are sourced directly from each jurisdiction's own government website (or, where a state government page did not state the fact directly, the state's own legislature or a named official document), cited per entry; check each entry's cited source before relying on it. Sales tax and state unemployment insurance entries represent a recurring quarterly (or monthly) filing pattern, not a single annual deadline - actual filing frequency is assigned per business by each state; treat these as illustrative of the pattern, not a confirmed date for your specific filing frequency. The pass-through entity layer covers the base partnership/S-corp entity-level return due date only; it does not cover state PTE elective-tax elections or payment deadlines, which vary by state and are not yet built. The federal holiday set used for the weekend/holiday shift does not include DC Emancipation Day (observed mid-April), which in some years pushes the individual federal return deadline one day later than this calendar computes - always confirm the individual filing deadline against IRS.gov for the specific year. This site is a reference tool, not tax advice; confirm any deadline against the official source cited before relying on it. An extension of time to file is not an extension of time to pay tax that is due.
